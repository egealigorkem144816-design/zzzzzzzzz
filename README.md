# İşaretli Aşçı

Türk İşaret Dili jestleriyle malzeme eşleştirerek yemekleri tamamladığınız eğitici bir Pygame oyunu.

## Çalıştırma

```bash
python -m sign_chef.game
```

Oyunda toplam 20 seviye vardır. Menüde "OYNA" düğmesine tıklayıp seviyeleri sırayla oynayabilir, her seviyedeki işaret kartlarını tabağa sürükleyerek doğru malzemeleri yerleştirebilirsiniz.
